# Subiksha Certificate Verification

This is a simple, real QR-based certificate verification website.

## How it works
1. The certificate QR code opens `index.html?id=SMA-2026-001`.
2. The webpage checks the certificate ID against the `records` object.
3. If the record exists, it displays "CERTIFICATE VERIFIED" and the certificate details.

## Before publishing
1. Open `index.html`.
2. Replace the sample record with the REAL student/certificate details.
3. Choose a public website address, such as:
   `https://YOUR-USERNAME.github.io/subiksha-certificate-verification/`
4. The QR currently points to:
   `https://YOUR-USERNAME.github.io/subiksha-certificate-verification/?id=SMA-2026-001`
5. Replace `YOUR-USERNAME` with the actual GitHub username.
6. Regenerate the QR if the final website address differs from the QR URL.
7. Publish the folder using GitHub Pages.

## Important
Only use genuine academy details and genuine accreditation/registration claims. The verification page should not be used to imply government accreditation unless that accreditation is actually held.
